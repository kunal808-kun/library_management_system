
# Library Management System

## About
A console-based Library Management System developed using Python and Oracle SQL.

## Features
- Add books
- View all books
- Search books by title
- Borrow books
- Return books
- Delete books

## Technologies Used
- Python
- Oracle Database
- python-oracledb

## How to Run
1. Install Python.
2. Install the required package using `python -m pip install oracledb`.
3. Configure your Oracle database connection.
4. Run `python library_management.py`.
